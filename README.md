# 広告集計ツール

## 概要
複数の広告媒体の広告データを登録・検索するためのWebアプリです。
期間、媒体、キャンペーンを条件に広告データを検索できます。

## 開発環境
- PHP
- Laravel
- MySQL
- JavaScript

## 機能
- 広告データ検索
- 広告データ登録、更新
- 媒体登録、更新
- キャンペーン登録、更新

## テーブル
- medias(媒体マスタ)
- campaigns(キャンペーンマスタ)
- addatas(広告データ)

## 工夫点
- 検索条件による絞り込みについて、検索ボタン押下後も検索条件を保持
- テーブルヘッダ押下時に昇順・降順で並び替えできる機能を実装
- 数値項目（インプレッション、クリック、コスト、CV）は右寄せで表示するよう実装
- マスタ登録時にIDの重複をチェックし、重複データの登録を防止するよう実装
- 更新完了画面を表示し、処理結果を利用者が確認できるようにした
- 媒体マスタで有効としたデータのみ、検索画面の媒体マスタコンボボックスに表示/選択できるようにしている
